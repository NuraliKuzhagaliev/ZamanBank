# Zaman

Интерактивный концепт финансового сервиса, созданный для хакатона. В демо можно посмотреть финансовый кабинет, создать цель накопления и поговорить с помощником. Финансовый кабинет работает локально в браузере; для AI чата можно подключить Groq через Vercel Function.

![Главная страница Zaman](preview.png)

Сайт опубликован на GitHub Pages: [открыть Zaman](https://nuralikuzhagaliev.github.io/ZamanBank/).

## Запуск

Нужен Node.js. Из папки проекта в PowerShell:

```powershell
node .\server.cjs
```

Откройте [http://127.0.0.1:4173](http://127.0.0.1:4173). Для проверки ссылок и синтаксиса:

```powershell
npm.cmd run check
```

`npm.cmd run dev` тоже запускает сайт в PowerShell. Обычная команда `npm` на некоторых Windows блокируется политикой запуска PowerShell.

Можно разместить файлы как статический сайт. Для разработки открывайте сайт через локальный HTTP сервер, поскольку браузерные ES модули могут не работать при открытии HTML через `file://`.

## Что можно попробовать

1. На главной нажмите **Попробовать демо**.
2. Введите вымышленные email и пароль длиной от 6 символов. Это имитация входа, пароль никуда не отправляется и не сохраняется.
3. В кабинете создайте финансовую цель. Она останется в `localStorage` этого браузера после перезагрузки.
4. Откройте помощника и выберите готовый вопрос.

## Подключение Groq к опубликованному сайту

Функция `api/chat.js` предназначена для Vercel, а сайт остаётся на GitHub Pages. Ключ Groq должен находиться только в переменной окружения Vercel `GROQ_API_KEY`, никогда в файлах репозитория, `ai-config.js` или браузере.

1. Импортируйте этот GitHub репозиторий в Vercel как проект с корнем `./`. Для статического проекта не требуется команда сборки.
2. В настройках проекта Vercel добавьте Environment Variable `GROQ_API_KEY` для Production, вставьте ключ и запустите новый Production deployment.
3. Проверьте адрес `https://<имя-проекта>.vercel.app/api/chat`. При открытии в браузере допустим ответ о неподдерживаемом методе: функция ожидает POST с сайта.
4. В `ai-config.js` укажите публичный адрес функции целиком, например `https://<имя-проекта>.vercel.app/api/chat`, и обновите файл на GitHub. После публикации GitHub Pages чат переключится с заготовленных ответов на Groq.

Для тестирования без ключа `npm.cmd run check` проверяет формат запросов и обработку ответов с подменённым Groq API. Бесплатные лимиты Groq применяются ко всем посетителям. Ограничение по Origin в функции уменьшает случайные вызовы из других сайтов, но не заменяет защиту от автоматизированного расходования квоты; для публичного сайта добавьте ограничение частоты запросов в Vercel Firewall.

## Границы демо

Zaman не является банком. Баланс, операции и журнал администратора демонстрационные. Пока Groq не подключён, ответы помощника тоже заранее подготовлены. После подключения текст сообщений отправляется Groq для генерации ответа, но помощник не получает доступ к банковскому счёту и не выполняет переводы. Банковской авторизации и серверной защиты демо кабинета нет. Не вводите настоящие пароли, реквизиты или другие чувствительные данные. Контактная форма удалена, поскольку у проекта нет сервера для отправки сообщений.

## Структура

- `index.html`, `project.css` — главная и общий визуальный стиль.
- `dashboard.html`, `dashboard.js` — кабинет и цели.
- `ai_assistant.html`, `ai_chat.js`, `ai-config.js` — чат и публичный адрес функции.
- `api/chat.js` — серверная функция Vercel, которая хранит ключ в окружении и вызывает Groq.
- `api.js` — API слой; по умолчанию включён локальный mock режим.
- `auth.js`, `ui.js`, `validator.js` — состояние демо входа, интерфейс и проверка форм.
- `server.cjs`, `checks.cjs` — локальный сервер и базовая проверка проекта.

Для превращения концепта в реальный финансовый сервис потребуются бэкенд, безопасная авторизация, хранение данных на сервере, подтверждение операций и юридическая проверка банковских и исламских финансовых продуктов.
